# Flowchart Builder

**Flowchart Builder** is a convenient and modern application for teaching children programming. Here you can write or paste code in C++ or Python from a file and understand its logical structure thanks to the flowchart. Two interface languages are supported: Russian and English. Recommended for computer science teachers.

## 📥 Installation

### Option 1: Ready-to-use application (.exe)

1. Go to the **Releases** section of this repository.
2. Download the `Flowchart Builder.exe` file.
3. **Recommended**: Place the `.exe` file in a separate folder — on first launch, the program will create additional folders and files for storing data.
4. Run `Flowchart Builder.exe`.

### Option 2: Running from source code (.py)

1. Download all repository files.
2. Make sure you have Python 3.x installed.
3. If there's a `requirements.txt`, install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Launch the application:
   ```bash
   python main.py
   ```

> 💡 You can modify the code to suit your needs.

## 🎮 Controls

| Action | Control |
|--------|---------|
| Move flowchart | Left mouse button |
| Change scale | Mouse wheel |
| Center and auto-scale | Press mouse wheel |

## 📁 Working with files

- **Save as** — create a new file with code and flowchart.
- **Save** — overwrite the open file.
- **Load** — load code from a third-party file (programming language is automatically detected by file extension: `.cpp`, `.py`).
